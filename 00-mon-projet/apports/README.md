# Apports · ce que vous déposez ici

Glissez vos fichiers dans le bon dossier (depuis l'explorateur de VS Code, ou depuis votre ordinateur),
puis dites à Claude « c'est déposé ». Il les regarde, les range dans l'inventaire de `../projet.md`, et
s'en sert au bon moment.

| Dossier | Quoi | Formats |
|---|---|---|
| `logo/` | votre logo, en couleur et en blanc si vous l'avez | SVG de préférence, sinon PNG transparent |
| `photos/` | le produit, l'équipe, le terrain, le prototype | JPG, PNG, WebP ; les originaux, Claude les optimise |
| `charte/` | une charte existante, des couleurs, une police | PDF, images, liens dans un fichier texte |
| `inspirations/` | 3 à 5 sites ou visuels qui vous font dire « waw » | `liens.md` (un lien par ligne et ce que vous aimez), captures d'écran |
| `documents/` | deck, présentation, étude, notes d'entretiens | PDF, DOCX, PPTX, MD |

**Ce qui ne va jamais ici** : mots de passe, clés d'accès, fichiers de clients avec emails ou téléphones.

Les photos de personnes : seulement avec leur accord pour une publication.
