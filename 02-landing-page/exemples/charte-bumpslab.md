# Charte graphique · exemple BUMPSLAB

> L'exemple suivi en formation, tiré du design system de bumpslab.com. Il montre la forme d'une charte
> utilisable par Claude. Ne reprenez pas ces couleurs ni ces règles pour votre projet : faites les vôtres.

## Typographie

- **Une seule famille** : Geist (Google Fonts), et Geist Mono pour les numéros et les éléments techniques.
- **Titres** : Geist 450. **Texte courant** : Geist 300. Emphase dans un texte : 500.
- **Mise en avant dans un titre** : un à cinq mots, en Geist normal, soulignés d'un filet vert de 1,5px.
  Jamais d'italique ni de deuxième police pour ça.

## Échelle des tailles

| Usage | Mobile | Ordinateur |
|---|---|---|
| Titre principal | 40px | 72px |
| Titre de section | 30px | 48px |
| Sous-titre | 18px | 22px |
| Texte courant | 16px | 17px |
| Légende, numéro | 13px | 13px |

Interlignage : 1,1 pour les titres, 1,6 pour le texte. Lignes de texte de 60 à 70 caractères au plus.

## Couleurs

| Nom | Hex | Usage |
|---|---|---|
| Nuit | `#0B0F0D` | sections sombres |
| Vert | `#1A4535` | signature : boutons, soulignés, numéros. **Jamais plus de 5 % de la page** |
| Surface | `#F4F4F4` | fond des sections claires |
| Encre | `#12130F` | texte courant |
| Papier | `#FAFAF7` | fond principal |
| Encre douce | `#737373` | légendes, textes secondaires |
| Vert pâle | `#C5D3CC` | soulignés sur fond sombre |
| Filet | `#D4D4D4` | bordures fines |

Contraste minimum WCAG AA : 4,5:1 pour le texte, 3:1 pour les grands titres.

## Espacements et arrondis

- **Entre deux sections** : 96px sur ordinateur, 64px sur mobile.
- **Marges latérales** : 16px sur mobile, 48px sur ordinateur. Contenu centré, 1200px de large au plus.
- **Arrondis** : 16px pour les cartes, 10px pour les boutons et les champs.
- **Boutons** : 44px de haut au minimum (taille d'un doigt).

## Vocabulaire visuel

- Repères de section au format `01 / Libellé` : numéro en Geist Mono vert, barre oblique, libellé.
  Seulement quand le contenu est vraiment une suite.
- Séparateurs : la barre oblique `/`, jamais un tiret long.
- Le bouton principal est encadré de crochets verts fins.

## Icônes et images

- Icônes : bibliothèque Lucide, trait fin, une seule couleur.
- Images : photos réelles de l'équipe et captures du produit. Pas d'images génériques de robots ni de
  cerveaux lumineux.

## Sites de référence

- harvey.ai : la sobriété, les grandes respirations entre sections.
- rogo.ai : les captures produit mises en scène, sans décor.

## Interdits

- Aucune ombre portée.
- Pas de capitales espacées (texte tout en majuscules avec lettres écartées).
- Jamais de rouge d'alerte.
- Jamais de tiret long (—) ni de tiret moyen (–) dans les textes : une virgule, deux-points ou une barre
  oblique à la place.
- Pas de mots creux : « révolutionnaire », « innovant », « next-gen », « game-changer ».
- Le vert en grand aplat dominant.
